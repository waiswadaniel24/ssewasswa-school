# Ssewasswa School ERP (local workspace)

Quick run instructions (development):

1. Install dependencies

```bash
npm install
```

2. Run in development (Vite + Electron)

```bash
npm run dev
```

3. Lint and format

```bash
npm run lint
npm run format
```

Notes:
- This repository is an Electron + React app using a local sql.js database.
- The repository now includes basic lint/format configs and a CI workflow placeholder.
